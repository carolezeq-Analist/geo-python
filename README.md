# geo-python
Daily STAC &amp; LiDAR experiments exploring INPE's STAC catalog and advanced terrain/vegetation analysis. From Sentinel-2 indices (EVI/NDVI) to Canopy Height Models (CHM) from LiDAR point clouds. Scripts include DEM processing, hillshade, slope, curvature, and 3D visualizations. A portfolio of geospatial fundamentals in Python.
